# 海洋主题性能优化（本地，2026-10-23）

用户反馈加载、切换页面慢且滚动/动画卡顿。本次直接修复性能，不改变已批准的页面布局、色彩、透明度、图片像素、画布分辨率或气泡运动规则。

- 14 张新增主题 PNG 转为 WebP lossless + exact，尺寸及完整 RGBA 逐像素一致，原文件保留。合计 20,283,601 → 15,019,552 字节，减少 25.95%。新路径 `/media/ocean-20261023/`。
- 内页不再错误预加载首页水母壁纸。详情页背景、动画底板、气泡和按钮的理论首访主题资源合计 8,934,728 → 5,249,540 字节，减少 41.25%；这是资源量估算，不是实际访问耗时降幅。
- 不变的着色器参数仅初始化/尺寸变化时上传，人物与手部的时间函数每帧计算一次，复用 typed arrays。保持相同位移公式；画布尺寸未变时避免重复分配。
- 120/144/240Hz 屏幕每秒最多约 60 次绘制，模拟仍按真实时间推进；60Hz 保留原节奏。隐藏页面暂停、恢复不跳时、销毁清理保留。取消 15 秒图片加载截止，慢网成功下载后仍可开启动画；明确图片错误与不支持 WebGL 仍保留静态背景。
- 本地 Nginx 模板新增版本化图片一年 immutable 缓存规则，尚未部署；上线前须在实际 Nginx 检查、备份并平滑重载，只改对应媒体 location，保留所有撤下资源规则。新增公开目录权限需在切换前校验 0755，不能沿用上次解包 0700 问题。
