# 下拉框与固定导航的滚动兼容

商城根元素通过 `scrollbar-gutter: stable` 预留滚动条位置，不设置 `overflow-y: scroll`。否则 Reka 下拉框锁定 `body` 的滚动时，`body` 会成为新的滚动容器，分销控制台的 sticky 顶栏和侧栏会跟随正文移出屏幕。

`App.vue` 的 `ConfigProvider` 将滚动锁定时的额外 padding/margin 设置为零，避免在已预留的滚动条位置上重复补偿，导致内容横向移动。保留组件原有背景滚动锁定、焦点管理与键盘交互，不在下拉框中手工恢复滚动位置。

验证使用日常本地 `5173` 与后端 `8080` 的临时分销账号：在长商品列表中展开商品级和 SKU 级定价下拉框，比对开关前后的 `scrollY`、顶栏和侧栏坐标，覆盖鼠标选择、键盘选择、Esc、1920/390/320px、手机导航和其他商城弹层。打开编辑器仅使用价格预览，不保存验收价格规则。

本改动仅涉及商城前端。发布保留后台资源、后端程序、分销运行配置、订单与价格数据；本地账号和验收记录在验证后清理。截图、坐标与发布证据位于忽略目录 `work/codex-runtime/dropdown-scroll/`。
