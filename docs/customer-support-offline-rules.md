# 客服离线规则与验收

2026-10-19，规则版本 `2026-10-19.1`。本地分支 `codex/customer-support-agent`，入口 `http://127.0.0.1:5175/?template=classic`，独立 Agent 监听 `127.0.0.1:8085`。未发布 Agent 到正式站。

## 内部结构

- `internal/modules/supportagent/policy-data.json`：嵌入构建的已确认规则与 27 款商品 slug → 规则组映射。新商品必须明确映射，不从标题推断质保。
- `policy.go`：本地意图分流、商品范围判断、缺项追问、临时会话状态、人工材料说明。未知规则转人工，不调用外部知识补全。
- 退款试算依次收集实付金额与币种、实际开始时间、原到期时间、实际掉订阅时间。重开另收集同币种的当前售价。金额用整数分和大整数有理计算，最后半入舍入；不按固定 30 天，不换汇、不猜日期。
- 缺资格的商品不进入通用试算。Gemini 特殊质保、Telegram 激活、Codex 点数到账独立处理。重开售价由客户提供且明确标记为试算，未声称已读取实时正式售价；特殊负差额交人工。
- 异常时可记录用户提供的订单号并整理人工材料提示，但无订单数据库读取权限、无截图上传、无实际工单转交。订单号在内存会话中，跟随会话过期清理，不记录消息正文日志。
- 原 Host/Origin、请求长度、频率、并发、请求 ID 防重以及 HttpOnly 会话保护保留。会话/语言改变重置业务状态，切换商品清空试算槽位，页面提供“开始新会话”。

## 模型与权限边界

启动器默认不传 `-allow-model`，默认离线；显式使用 `start -AllowModel` 才开启。历史私有密钥或配置不能自行开启模型。离线验收须确认健康检查 `model_enabled:false`。离线分支不访问 Provider、目录检索或用量账本；业务规则不依赖本地旧商品文案。密钥和用量账本保留，不清空。

即使显式开启模型，已识别的质保、退款、资格及相关会话仍优先走确定性规则，不交给模型计算金额。2026-10-19 按用户要求增加六个业务工具，并接入 DeepSeek 工具调用：其他问题可由模型选择查询、规则、试算及人工材料工具，规则与直答共用；商品描述不能覆盖已确认规则。离线模式未覆盖的表达仍转人工。模拟协议测试、规则直答验收和真实模型验收必须分别记录，不能互相代替。工具清单与限制见 `customer-support-deepseek.md`。

全部退款、补发、卡密销毁、订单修改由人工执行。未确定的商品/金额/资格/到账情况，不作承诺。具体兑换入口仅在已付款订单交付中提供；不在客服中收集密码、token、完整卡密。

## 离线验证

45 项 Go 测试（含子案例）通过，覆盖已有安全/预算模拟测试及新增业务矩阵、二月与闰年、半分舍入、非法区间、缺币种与跨币种、重开差额、商品切换、会话隔离、防重复、材料收集。测试用 nil 账本/知识库与计数 Provider 证明离线请求不访问模型或计费账本，并验证可选模型打开时退款流程仍不调用模型；所有 Provider 网络测试只使用本机 httptest 服务。

商城 177 项测试、类型检查、生产构建通过。最后快捷提问文案变更追加 3 项接口回归及类型检查。实际浏览器完成五轮试算：100 CNY，2026-02-01 至 2026-03-01，2026-02-15 掉订阅，结果 50.00 CNY。该结果仅为虚构测试数据，没有创建/修改订单。

主工作区 `deployment/local/customer-support-knowledge/` 保存私有测试日志和线上第 2 次商品文案变更报告。正式只更新商品中文文案，未发布此分支程序。正式价格/库存/上下架/交付模式/私有交付/历史订单与正式服务均保持，主目录本地旧商品数据未自动同步。
