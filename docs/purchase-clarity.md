# 商品购买与结账信息

2026-10-15：购买区增加条件摘要和兑换入口，结账提交区突出含支付手续费的合计。classic 与 vault 使用同一组件，支持简体、繁体和英文。

## 商品条件与兑换

`frontend/user/src/utils/productPurchaseGuide.ts` 仅按已审核的商品 slug 分组，不根据相似标题推断套餐。摘要来源为当日线上商品详情，文案集中在 `frontend/user/src/i18n/purchaseClarity.ts`。

- 新开通和 Pro 20x 续费分别展示条件；Codex 点数要求已有有效订阅，不包含或延长订阅。
- Gemini 保留 Jio、账号年龄及质保的商品差异，使用订单发放的兑换链接，不使用 ChatGPT 兑换页。
- ChatGPT 与 Codex 的可见兑换入口为 `https://cdk.bar/`，新标签打开。详情中原有的“打开兑换页”和无 href 的“兑换页”同步补全链接。
- 不确定资格时先联系客服，不宣称付款前已完成资格检测，也不新增退款承诺。

**维护要求：**以后变更后台商品资格或质保规则时，同步维护对应摘要与三种语言文案；未知商品默认不展示此摘要，不套用其他套餐条件。原完整商品说明继续展示，生产数据库中的商品说明和交付快照不回写。

## 实付金额

结账上方金额改名为“商品小计（优惠后）”，不再称为预估应付；无折扣时隐藏零优惠行。支付方式下方、提交按钮上方增加统一金额摘要：商品小计、支付手续费、实付合计。

沿用 `useCheckout` 和 `money.ts` 的现有金额与分取整规则，不改收款逻辑：

- 实付合计 = 商品优惠后金额 + 在线支付手续费。
- 余额抵扣包含在实付合计中，另列余额支付和剩余在线支付；余额全额支付时合计不能显示成 0。
- 未选择支付方式或金额更新中，不展示确定的手续费与合计。
- USDT 选择页显示人民币订单金额，付款页提供最终网络和精确 U 数量，转账手续费另计。
