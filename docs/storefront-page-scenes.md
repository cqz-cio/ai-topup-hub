# 商城分组场景（2026-10-22，本地）

用户批准三组设计并要求本地查看后实现；尚未推送或上线。

| 场景 | 页面 | 人物 |
| --- | --- | --- |
| street | 购物车、结账、付款 | 蟹老板、珍珍，蟹堡王街景 |
| garden | 商品中心及分类、博客及正文、公告、关于、隐私和条款 | 珊迪、派大星，珊瑚花园 |
| home | 登录、注册、找回密码、个人中心及子页、查单和订单详情 | 海绵宝宝、小蜗，菠萝屋 |

路由映射在 `frontend/user/src/utils/brandPageScene.ts`，App 根节点以 `data-brand-page-scene` 标识场景；统一样式位于 `frontend/user/src/styles/brandPageScenes.css`。仅主站 classic 生效，保留首页、商品详情、Vault、分销和独立页面既有行为。

三张 1672×941 纯背景放在 `frontend/user/public/brand/scenes/`，通过固定伪元素 cover 展示，不随正文滚动或重复平铺。页脚透出同一背景。手机裁切至一侧人物，正文玻璃底适度加深；深色模式使用原图暗化与深色玻璃。保留二维码白底，不改付款、售价、库存或订单逻辑。

主要按钮复用已批准的海浪 PNG，文字和图标仍是网页内容。通用 Button 增加主按钮及图标尺寸标记，外观覆盖只在新场景根节点内生效。商品中心保留完整商品内容和三列/窄屏布局，桌面最大宽度保持 1240px，中等桌面预留两侧场景空间。

核验记录见根目录 `design-qa.md`；截图和已移出应用目录的临时尺寸工具保存在 `work/design-preview/site-scenes-20261022/implementation/`。156 项既有测试、类型检查和最终构建通过。支付中的有效订单及登录后的个人中心未进行端到端操作，本次未创建订单或实际付款。
