# 小π客服：DeepSeek 本地调试

本功能在 `codex/customer-support-agent` 独立分支开发，已吸收本次 main 同步，Agent 尚未发布到正式网站。源码提交、远端同步和实际运行状态分别核验。入口为 `http://127.0.0.1:5175/?template=classic`，派大星外观、连续动作和鼠标拖动保留。

## 运行与密钥

独立客服 Go 进程只监听 `127.0.0.1:8085`。前端通过 Vite 的 `/api/v1/support` 代理访问它，商城其他 API 继续使用已有的本机 `8080`。客服程序只读公开商品接口，不打开商城数据库，不携带商城登录令牌，不连接生产服务器、供应商或支付接口。

在客服工作区根目录执行：

```powershell
pwsh -NoProfile -File scripts/local/support-agent.ps1 start
pwsh -NoProfile -File scripts/local/support-preview.ps1 start
```

修改客服 Go 源码后，仅停止并重建该服务：

```powershell
pwsh -NoProfile -File scripts/local/support-agent.ps1 stop
pwsh -NoProfile -File scripts/local/support-agent.ps1 start -Build
pwsh -NoProfile -File scripts/local/support-agent.ps1 status
```

`support-preview.ps1 stop` 仅停止该分支前端；`support-agent.ps1 stop` 停止客服进程。PID、启动时间和独立日志保存在忽略的 `work/codex-logs/`。脚本核验所属进程后再停止，构建有 120 秒超时，服务有健康检查；不管理日常商城、Redis 或线上进程。

默认启动仍关闭付费模型。显式开启现有 DeepSeek 模型及工具调用：

```powershell
pwsh -NoProfile -File scripts/local/support-agent.ps1 stop
pwsh -NoProfile -File scripts/local/support-agent.ps1 start -AllowModel
```

重新停止并不带 `-AllowModel` 启动即可恢复离线模式。开关由维护者控制，会话不能自行开启。只改私有配置不能打开模型。最终状态以 `/api/v1/support/health` 的 `model_enabled` 为准；该接口同时返回工具数量和轮数上限。前端打开客服或发送问题时读取此状态，三语言提示随之切换；状态读取失败时使用中性提示，不误报“离线、不调用 AI”。

密钥只在本机忽略文件 `work/codex-runtime/support-agent/private/config.json` 中，文件夹 ACL 限当前用户与 SYSTEM。使用者在本机私密编辑器维护，不放进命令参数、Vite 环境变量、前端代码、Git、截图或日志。配置未提供或非法时拒绝启动。这个目录同时保存 `usage.db` 及其 SQLite WAL 文件，保留它们才能延续额度记录，不能当临时缓存清理。

配置字段：`api_key`、`model`、`max_output_tokens`、`daily_budget_nanousd`、`daily_calls`、`session_daily_calls`、`session_per_minute`、`global_per_minute`。当前值见下表，密钥不在文档中。改配置后重启客服服务。

## 模型与成本控制

使用官方 `https://api.deepseek.com/chat/completions` 的 `deepseek-flash`，关闭思考和流式输出。服务端仅开放下述六个只读/试算工具，不开放任意搜索、浏览器、代码执行或客户端自选模型。协议参考 [DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)。

| 限制 | 当前本地值 |
| --- | --- |
| 输入 | 500 个 Unicode 字符，HTTP body 最多 4 KiB |
| 输出 | 每次最多 800 token |
| 上下文 | 最近 6 轮、最多 9000 字节；初始消息最多 28000 字节；单次消息与工具定义合计最多 48 KiB；单个工具结果最多 12 KiB |
| 会话 | HttpOnly / SameSite=Strict cookie；闲置 30 分钟过期；最多 200 个内存会话 |
| 频率 | 会话请求和实际模型请求分别限流：每会话每分钟 6 次，全局每分钟 20 次；每一轮模型调用都计数 |
| 并发 | 每会话 1 个；全局 2 个 |
| 每日调用 | 全局 100 次；每会话 50 次；以北京时间日历日计 |
| 每日预算 | 保守估算 0.25 美元；到任一上限即拒绝模型调用 |
| 超时 | 模型 35 秒，完整服务请求 45 秒；不自动重试 |
| 工具循环 | 每条消息最多 3 次模型调用、6 次工具请求；单轮最多 3 个工具，最后一轮禁止继续调用工具 |

SQLite 在每次模型请求前原子预占费用及次数，输入估算包含工具定义和此前的工具结果，已知 usage 再结算；网络失败、取消或结果不明的预占保留，重启不清零。工具选择和最终回答均占每日次数；第二轮额度不足就停止，不自动重试。重复 request ID 不会重走已付费的第一轮，成功回复继续走原请求缓存。账本只记录不可逆摘要 ID、日期、计数、token 和费用，不存聊天或工具参数。每分钟限流和会话历史在内存中，重启会丢失，持久化的每日全局限额仍有效。

## 六个工具与规则直答

定义与执行入口在 `internal/modules/supportagent/tools.go`，商品适配器在 `catalog_tools.go`，多轮模型编排在 `tool_loop.go`。前端继续使用原聊天接口，不增加可由浏览器任意执行工具的入口。

| 工具 | 输入与用途 | 边界 |
| --- | --- | --- |
| `lookup_product` | 商品关键词或 slug，返回候选、详情、公开价、规格及缺货状态 | 搜索候选附已确认购买条件，详情附完整规则，优先于商品描述；返回抓取时间与本地快照说明；长规格截断并标记 |
| `get_product_policy` | 商品 slug、规则主题，返回确定的购买与售后规则 | 未知商品返回缺项；不将商品标题当资格证明 |
| `get_payment_guidance` | 订单/钱包场景，返回支付方式、手续费规则和教程 | 说明支持的支付业务；不生成付款、不查到账 |
| `estimate_after_sales` | 商品、退款/重开意图、实付、币种和真实时间，返回试算 | 仅适用 GPT/Claude；金额日期须能在用户消息中找到；不执行退款 |
| `get_troubleshooting_guide` | 已报告的异常类型，返回排查和材料说明 | 不读订单，不确认支付或兑换成功 |
| `prepare_handoff` | 已报告的问题类型，整理材料及人工联系方式 | 返回 `submitted:false`，不创建工单或联系他人 |

所有工具使用服务端固定参数白名单，拒绝未知工具、额外字段、重复 JSON 键、错误类型/枚举和任意 URL 参数。结果包含状态、结构化数据、缺项和规则版本，执行后由服务端分配 `source_id`；模型只能引用本次已返回的来源。站内链接仍由后端生成并由前端再校验。

模型初始上下文只保留一般选购、订单导航和合作说明，不预先塞入完整支付规则、商品售后规则和人工联系资料。需要这些业务事实时由对应工具读取，避免工具已经存在却继续从重复的提示资料直接作答。原有确定性规则仍先运行，未关闭或强制改走模型；提供给 DeepSeek 的 `tool_choice` 仍为 `auto`，测试请求没有指定工具名。工具引用须使用结果外层 `source_id`，内部规则编号不能冒充资料来源；校验拒绝日志只记录固定错误类别，不记录用户输入、工具参数或模型回复。

问候、明显敏感内容、已识别的业务规则及正在进行的售后流程仍先走原本的确定性直答，不调用模型或计费账本。直答与工具复用同一规则数据、支付说明、异常指引和整数金额计算。需要模型理解的其他问题才进入工具循环；工具不修改原本的会话业务状态。工具选择不是保证正确的语义识别，仍需实际问题评估。

退款试算和人工接续结果由后端直接呈现，避免模型改写金额或误报已提交操作，也省去一次回答生成。其余查询结果按 `assistant.tool_calls` → `role:tool` / `tool_call_id` → 最终 JSON 回答返回给模型。重复工具参数在单次会话请求内复用结果；工具返回数据不作为指令。`tools_used` 只在响应中记录执行过的工具名，不记录私有参数。

费用估算采用 2026-10-16 查到的 Flash 峰时未缓存单价：输入 $0.30 / 百万 token、输出 $1.20 / 百万 token；忽略缓存和谷时优惠，预占输入按 UTF-8 字节数加余量计。此值是本程序的保守估算，不是供应商账单或其控制台硬限额；供应商调价必须同步 `ledger.go`。参考 [官方价格](https://api-docs.deepseek.com/quick_start/pricing/)。

## 对话与资料边界

- 浏览器只提交当前消息、语言、商品 slug、会话与请求 ID；不接受自定义 system prompt、history、tools 或模型参数。会话上下文由客服后端维护，刷新页面开始新对话，语言切换取消旧回复并重置上下文。
- 小范围整句规则处理问候、人工入口、明显凭据，以及“今天天气咋样”等明确站外问题，不调用模型。带商城语义的“你们卖的 GPT 能查天气吗”、省略句“这个怎么用”等仍送模型结合上下文理解。模型范围约束不是零消耗分类器，复杂越界输入可能消耗一次受限回复，也不是百分之百的语义安全保证。
- 一般业务资料在 `knowledge.go` 维护；当前商品名、公开参考价及详情来自本机公开商品接口，60 秒缓存，最多 5 页。仅反序列化允许字段，剥离 HTML、脚本和网址，不读取交付私密字段。目录失败时明确只提供一般指引，不以旧缓存冒充当前商品状态。
- 浏览器商品 slug 先标注为未核验提示，价格、库存和详情须通过工具在公开目录核验；不能把客户端传入的地址作为抓取 URL。售前和聊天中都不展示具体兑换域名，只指向付款后的订单交付说明。
- 模型按 JSON 返回纯文本和资料 ID。后端检查结构、长度、来源 ID 与敏感链接；站内链接由服务端白名单生成，前端再校验。文本由 Vue 转义，没有 HTML 执行。来源 ID 校验不能自动证明每句话正确，具体业务细则仍需继续人工打磨。
- 暂不读取私人订单、支付状态、钱包余额、佣金或实际兑换结果；不能退款、补发、付款、充值或采购。未知规则澄清或转人工，联系方式保持微信 `Cqz0924ttxk`、QQ `1669268759`、Telegram `@czq_piestar`。
- 模型看到的是必要聊天上下文和公开资料。邮箱在发送前隐藏；明显 key、token 或长凭据直接提示重述，但这不是完整 DLP 系统。模型启用时前端明确标识 AI 辅助，提示勿提交密码、登录 token 或完整卡密。聊天不写入应用日志或数据库；异常只记录固定错误分类和 HTTP 状态，不记录供应商响应原文。
