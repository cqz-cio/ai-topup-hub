向本站客服提供订单号、商品名称、发生问题的环节、操作时间和脱敏后的错误截图即可先开始核查。不要在公开评论、论坛或搜索页面粘贴密码、完整卡密、会话凭证或 API 密钥。客服联系方式见关于我们；游客可用下单邮箱与查询密码进入游客查单。

确认开通后，还需要看什么？

核对目标账号的套餐状态和可见的订阅时间，并保存订单记录。会员显示正常后，如某项功能仍不可用，应再区分套餐权限、使用额度和服务状态；这类问题不一定属于充值未到账。
