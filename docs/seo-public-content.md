# 商品与文章公开正文（2026-11-05，仅本地验证）

基于 `39e109a00fbe88d4ab8ae29008f293e159e0cc51` 及此前未提交的 SEO P0 修复。未提交、推送或上线；正式业务库、配置和服务未改动。

## 本次行为

- 原商品地址 `/products/:slug`、文章与公告地址 `/blog/:slug` 直接返回包含完整公开正文的 HTML，支持 GET、HEAD。不执行 JavaScript 也能阅读标题、摘要、说明、图片、公开售价、供货状态、有效规格及关联链接。
- 内容实时读取现有公开用例；商品沿用上架、分类、租户售价和库存展示规则，文章沿用发布状态。只投影公开字段，HTML 不包含订单、卡密、私有交付说明、成本或客户专属价格。
- 所有 User-Agent 收到相同正文。没有爬虫专用隐藏文本，也没有新增另一套收录 URL。默认文案与前端首次访问的简体中文一致，缺省时回落英语；访客保存的语言仍由现有客户端处理。
- 服务端输出 canonical、description、Open Graph、Product / BlogPosting / Article JSON-LD。文章的结构化数据在 Vue 接管后继续保留，服务端标签在挂载时移交给 Unhead，避免重复及跨路由遗留。
- 无脚本模式为简洁、可阅读的正文页面；脚本加载后，由现有 Vue 应用接管，保留商城外观、选购和其他交互。
- 富文本经过 bluemonday v1.0.27 清洗，保留段落、标题、列表、表格、图片和安全链接；阻止脚本、事件属性和危险 URL。站内相对链接可跟踪，外部链接保留 nofollow。JSON-LD 使用 JSON 编码转义，防止正文中断 script 标签。
- 动态文档禁止缓存；下架商品、停用分类、未发布文章和不存在的地址返回真实 404 + noindex。读取故障返回 503 + noindex / Retry-After；网关失联保留 502，不回退为 200 首页。

## 实现与发布边界

- `internal/platform/http/publicpage`：通用 HTML、安全清洗、结构化数据与状态码；只接收公开页面模型。
- `internal/bootstrap/publicpage`：公开商品／文章投影与租户品牌组合。复用现有 Handler 的读取逻辑，API 会员价处理保持。
- `frontend/user/build/publicDocumentEntry.ts`：构建生成固定名 `storefront-entry.js` / `.css`，指向本次前端的哈希文件。后端无需内置上海静态站的具体哈希，前后端后续独立发布不会因哈希不同而失去交互。固定入口禁止长期缓存，哈希资产沿用现有缓存规则。
- 商城 Nginx 的详情路由优先保留真实图片文件，再代理后端 HTML；Vite 开发模式与内嵌静态资源模式同样保留图片访问。
- 本次只解决商品、文章／公告详情的原始 HTML 正文；首页、分类和列表页仍采用现有渲染方式，详情链接由现有 sitemap 提供。没有新增文章、改变售价或优化所有 SEO/GEO 内容项。
- 后续如获准上线，必须同时包含前端构建、后端和商城 Nginx 路由。先准备含固定入口的新前端与后端，验证固定入口 MIME/缓存及后端正文，再启用网关详情路由；不能只发布后端或 Nginx。回退关闭新增详情代理即可恢复原 SPA 入口，不恢复业务库。
