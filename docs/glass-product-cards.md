# 透明玻璃商品卡片

2026-10-19 按用户确认的透明玻璃方向实施。首页与商品中心共用的卡片增加透明渐变、轻微背景模糊、白色细边与内高光；页面原有水母背景使用完整不透明度显示。

## 范围与维护

- 样式入口：`frontend/user/src/components/commerce/StorefrontProductCard.vue`、`frontend/user/src/styles/commerce.css`。
- 只在经典主站的 `.brand-scene` 内应用玻璃材质。分销站保留原图与原卡片；Vault 保留自身外观。
- 16 张已有 GPT / Codex 矢量封面新增透明版本，放在 `frontend/user/public/catalog-products/glass-20261019/`。只移除底色、调整装饰与文字颜色，保留名称、倍率、地区和排版。
- `frontend/user/src/utils/catalogGlass.ts` 只映射明确列出的本站封面。上传图、自定义图和其他商品原图不替换；透明版本加载失败时先回退原图。
- 商品详情继续使用原封面。商品价格、库存、内容及选购入口仍来自现有数据与逻辑。
- 深色模式使用深色玻璃和浅色封面文字；背景仍为不透明图像，仅降低亮度。缺少 `backdrop-filter` 的浏览器使用更实的底色保证内容可见。

## 文字清晰度与浅色背景（2026-10-19 后续调整）

按用户确认的第二张预览，保留整张玻璃卡片，并将标题、价格和说明文字加深加重。标题为 17px / 700，说明为 13px / 550，价格为 28px / 750；手机标题为 16px。文字本身完全不透明。卡片为 7px 背景模糊配合轻微透明白色渐变，避免人物细节压住文字。

原水母背景图继续以 opacity=1 显示，通过 24% 白色柔化和 0.9 饱和度降低颜色浓度；深色模式不使用白色柔化。原封面、布局、商品及交易逻辑保持现有实现。该调整取代本文首次发布中“背景保持原图完整色彩”的描述。
