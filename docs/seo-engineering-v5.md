## 文案与相似度

草稿及逐页索引：[文案目录](catalog/seo-v5/README.md)、[13 页清单与待确认事项](catalog/seo-v5/copy.json)。未创建生产审批文件。

复用后台已有 `productContentSimilarity.ts` 的 3-gram Jaccard 算法，扩展档位、地区、周期替换的归一化；没有建立另一套检测器。以下为本地 HTTP 实际正文的最高两两相似度，验收阈值 < 0.85；全部规范化正文不相同。

| 商品簇 | 商品数 / 比较对数 | 正文最大值 | 整个公开页面可见文本最大值 |
| --- | --- | --- | --- |
| Telegram | 3 / 3 | 0.5734 | 约 0.558 |
| 自动发码（包含续费绑卡、Go 埃及） | 7 / 21 | 0.6485 | 0.6206 |
| 人工代充 | 3 / 3 | 0.6920 | 0.6730 |

Telegram 仍只确认时长差异，已有会员叠加、转赠及单账号次数不作新承诺；Go 自动发码不套用 Pro 十分钟条件，Go 人工只按现有 iOS 说明。Plus 两页和 Grok 八页的已确认正文不进入写库清单；Gemini 只换图片字段。

`scripts/seo_v5_content.py` 默认只读计划。正式 `--apply` 要求绑定清单、基线、13 篇 HTML 和图片字节摘要的确认文件；身份或当前文案发生变化则中止，不能覆盖新运营内容。使用事务、字段白名单、比较更新、备份、全表非目标字段核验及重复执行检查。合并或 CI 不会自动写库。
