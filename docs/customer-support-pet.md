## 渲染与动作

- `petRenderer.ts` 使用原生 WebGL 连续网格显示原画。保留原画已有明暗，只做小幅曲面视差；水平转向限制在 ±10°、俯仰限制在 ±5°，没有 360° 或侧背面展示。
- 右臂仍通过连续肩部权重挥动；腹部轻微凹陷回弹、视线跟随和换脚使用局部网格形变。眼镜反光在原图相应位置淡入淡出。透明像素不写深度，避免遮挡其他部位。
- `SupportPet.vue` 始终在外层处理位移、呼吸、摇摆和伸缩。轻微轮廓投影与脚下独立阴影增强悬浮层次；跳跃时地面阴影缩小、变淡、变软，落地恢复。保留平滑动作衔接、空闲动作、拖拽回弹、安静陪伴与减少动态效果。
- 原图加载完成后初始化画布；WebGL 不可用时显示原图并保留整体 CSS 动作。页面隐藏时暂停循环，卸载时释放资源。Three.js、其类型和 3D 原型测试已从运行源码及依赖清单移除。

## 历史：自然动作与轻立体感探索（2026-10-23）

- 保留原形象，新增四种空闲动作：左右观察、伸懒腰、换脚站、小跳跃。空闲间隔随机 2.4–5.7 秒，相邻自动动作不重复；聊天、菜单及鼠标关注角色时不自动开始大动作。跳跃和伸懒腰也可从菜单触发，选择后自动收起菜单以便手机查看。

## 使用

- 鼠标轻点肚子会局部凹陷、回弹；点身体其他位置挥手。双击开心摇摆，连续双击不叠加。鼠标靠近时上半身轻微转向，保留墨镜反光眨眼；空闲眨眼间隔随机 4–8 秒。
- 按住角色拖动，随移动方向倾斜，松手回弹；6px 内轻微位移仍视为点击，拖动不打开聊天。手机轻点角色直接打开客服，避免与页面滚动争抢。
- 底部「聊聊」始终是独立客服入口；角色的 Enter/Space 也可打开。Escape 收起菜单或聊天。已有问答、人工入口和新会话流程保留。
- 「…」或鼠标右键打开小角落：打招呼、开心一下、三档大小、安静陪伴、恢复右下角。玩耍动画和气泡均为本地逻辑，不请求客服接口或模型；只有聊天才访问原客服接口。
- 本机 `pi-companion-v1` 仅保存大小、休息偏好和归一化位置，不保存对话。刷新恢复；窗口缩放、改尺寸会约束可见范围。存储不可用或数据损坏时回到默认设置。手机不恢复桌面拖动位置。
- 安静陪伴停止循环动画；系统减少动态效果优先。后台标签暂停动画；无 WebGL 时仍显示原画和客服按钮。聊天处理中保留思考状态，玩耍不会打断回答。
