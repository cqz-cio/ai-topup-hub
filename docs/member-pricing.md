# 散客价与代理价

## 后台设置

1. 在「会员等级」中建立「散客」和「代理」。散客可设为默认等级、折扣率 100%，新注册用户会自动获得默认等级。代理如果仅允许管理员指定，请将充值、消费升级门槛都设为 0，关闭自动升级条件。
2. 在「商品管理」编辑每个商品及规格的基础售价，作为游客和未指定等级用户的散客价。
3. 在商品列表点击「等级价格」，分别填写各等级的「本商品默认价」及各规格固定价。例如普通规格散客价 100、代理价 70，高级规格散客价 200、代理价 130。不同商品可分别设置。
4. 在「用户管理」打开已注册用户的详情，在「会员等级」选择散客、代理或其他已配置等级。

没有配置等级时，价格面板提供会员等级管理入口。本次功能更新不会自动创建等级、调整现有商品价格或改变现有用户等级。

## 显示与结算规则

- 规格固定价优先于本商品默认等级价；两者均未填写时，按等级折扣率计算。散客等级不打折时保持基础售价。
- 留空并保存会清除对应固定价，不会留下旧价格；整个商品的等级价格在一个事务中保存。
- 延续原订单规则：固定等级价只在低于当前售价时生效，不叠加等级折扣；更低的促销或数量优惠不会被固定价抬高。
- 首页采用默认展示规格的一件价格，详情按当前选择规格和数量显示。购物车、立即购买和下单预览使用同一规则，最终金额由后端重新核价并写入订单。
- 后台调整用户等级后无需重新登录。重新加载商品或结算页面、回到窗口，以及可见页面每分钟刷新时会读取最新等级。退出或换账号后重新取价，不沿用上一账号的代理价。
- 未指定、已删除或停用的等级按基础售价及公开优惠计算。游客不能通过提交等级 ID 获取代理价；公开商品接口只返回当前用户所属等级的固定价。
- 个性化商品响应设置 `Cache-Control: private, no-store` 并保留 `Vary: Authorization`，防止不同身份共用缓存价格。

## 兼容与验证

复用现有会员等级、用户等级和商品等级价格表，无需新增数据库字段。后台价格接口复用现有读写权限；旧批量更新调用继续有效，带 `product_id` 的调用会完整替换该商品的等级价格。

回归测试覆盖等级价格的清除与恢复、跨商品隔离、事务失败回滚、最新用户等级、停用等级、促销和数量优惠、游客价格隔离，以及前台金额精度和购物车原价保留。

独立 SQLite 测试环境已通过真实后台保存、用户登录、首页、详情规格切换、购物车、结算预览与未付款订单验收。此验收不使用正式数据库、不发起支付。
