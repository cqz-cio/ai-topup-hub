# 下拉框与固定导航的滚动兼容

商城根元素通过 `scrollbar-gutter: stable` 预留滚动条位置，不设置 `overflow-y: scroll`。否则 Reka 下拉框锁定 `body` 的滚动时，`body` 会成为新的滚动容器，分销控制台的 sticky 顶栏和侧栏会跟随正文移出屏幕。

`App.vue` 的 `ConfigProvider` 将滚动锁定时的额外 padding/margin 设置为零，避免在已预留的滚动条位置上重复补偿，导致内容横向移动。保留组件原有背景滚动锁定、焦点管理与键盘交互，不在下拉框中手工恢复滚动位置。
