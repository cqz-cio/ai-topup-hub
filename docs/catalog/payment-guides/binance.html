流程：官方下载 → 注册与认证 → 准备 USDT → 创建本站订单 → 链上提币 → 返回本站查单。

01 下载与安装

打开币安 Binance 官方下载页（binance.com）。安卓和 iPhone 都从这个入口选择对应版本。

  • 安卓：按官方下载页提供的方式安装，核对来源；不要使用群聊或陌生人提供的安装包。
  • iPhone：由官方下载页进入 App Store，使用本人 Apple 账户。能否下载取决于所在地区及商店供应情况；显示不可用时，请查看官方说明。
  • 电脑：可通过币安官网使用网页端，或在官方下载页查看桌面版。

02 注册、认证与准备 USDT

用本人邮箱或手机号注册，按照币安提示完成身份认证和安全验证。密码、验证码只在官方页面输入，不交给代操作人员。

  1. 打开币安 App，在首页找到添加资金 → P2P 交易，选择「购买」及 USDT。部分版本或地区可能显示为「买币」「C2C」。
  2. 查看报价、金额限制、付款方式和可提现条件，再选择适合自己订单的选项。使用与实名认证一致的本人付款账户，按平台订单内的信息支付。
  3. 实际付款后，再按页面提示通知卖家；等待放币，并在资金账户核对 USDT。已经付款但没有放币时，通过平台订单申诉处理。

购买和提现功能以币安对你所在地区、账户的实际支持为准。先确认资金可提现、余额足够覆盖付款及提现费用，再创建本站限时付款订单。买到 U 只是资金进入你的币安账户，还没有支付给本站。

03 在 π星卡社获取付款信息

  1. 进入商品中心，阅读商品说明，选择规格并确认订单。游客请保存下单邮箱与查询密码。
  2. 在结算页选择本次订单可用的 USDT 渠道。记录付款页给出的币种、网络、完整收款地址、应付数量和剩余时间。
  3. 每次都从当前付款页复制地址和数量；不要沿用教程示例、旧订单截图或历史转账记录。

本站目前提供以下链上渠道，是否可用于该订单，以结算页为准：

  • TRON（TRC20）：转出端也选择 USDT 的 TRON / TRC20 网络。
  • BNB Smart Chain（BEP20）：转出端也选择 USDT 的 BNB Smart Chain / BSC / BEP20 网络。
  • Plasma：本站此渠道按 Plasma 网络的 USDT0 收款，仅在转出端明确支持对应网络和资产时使用。

网络名称必须对应，不能只看地址长得一样。X Layer、ERC20、Polygon 等不能替代付款页选中的网络；如果币安没有对应选项，先停止操作，改选双方支持的渠道或联系客服。

04 从币安向本站付款

常见入口为资产 → 提现／转出 → 提币 → USDT → 通过区块链网络发送。选择向外部地址提币，粘贴本站付款页地址，再选择与本站完全一致的网络。

  1. 核对收款地址、币种和网络，输入数量；查看页面显示的手续费和预计到账数量。
  2. 让收款方实际到账数量等于本站付款页的完整应付数量，包括所有小数位。
  3. 再次检查付款期限和所有信息，由你本人完成币安要求的安全验证并提交。
  4. 在提现记录查看处理状态；交易上链后保存交易哈希（TxID）。

金额示例（仅说明计算方式）：若本站应收 10.123456 USDT，且提现页明确从输入数量扣除 1 USDT 手续费，则输入 11.123456，核对最终到账为 10.123456。若 App 已按「收款金额」自动另加手续费，就不要重复加费。费用及最低提现额以当次页面为准，不承诺零手续费。

本教程对应本站链上收款地址。不要选择「转给币安用户」、UID、邮箱转账或 Binance Pay 来替代链上付款。

提交提现后，回到原付款页等待链上确认。交易所显示「已完成」代表转出处理完成，本站仍需核验到账。请勿重复转账。

  • 买完 U 不能提？先查看币安的可用余额、安全限制、最低提现额及网络状态；解除限制后再创建本站付款单。
