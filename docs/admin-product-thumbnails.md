# 后台商品缩略图

商品列表和批发价列表共用 `ProductThumbnail.vue`，按批准的 B 方案使用 100×60 横图容器、`object-contain` 和 8px 圆角，保持原图完整。图片加载失败或未配置图片时展示统一的「无图」占位；更换图片地址后自动恢复加载。

商品图片沿用数据库原始地址，不改商品封面、售价或库存。目录资源位于商城 `frontend/user/public`：

- 本地后台通过 Vite 将 `/catalog-products/` 及 `/products/` 下的图片文件转到日常商城端口 5173。
- 上海后台 Nginx 将相同路径映射到当前商城资源目录。`/products/` 只匹配图片扩展名，保留后台商品页面及其子路由。
- 缺失图片返回原有 404 HTML 错误页，图标和 API 错误透传规则继续生效。

只更新后台静态资源与后台 Nginx 配置，保留商城资源、后端、业务数据和私有配置。发布遵循先日常本地验证、再推送部署的流程。核验记录存放在忽略目录 `work/codex-runtime/product-thumbnails/`。
