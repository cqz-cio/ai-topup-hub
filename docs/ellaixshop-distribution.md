| 字段 | 值 |
| --- | --- |
| 名称 | ELLAIXSHOP |

| 站点地址 | `https://ellaixshop.com` |
| 商户 ID | `1039` |
| 商户密钥 | 该账户个人资料中的商户密钥 |
| 汇率 | `1`（上游进货与本站订单均为 CNY） |
| 加价比例 | 按实际售价和利润要求填写 |
| 自动同步价格 | 根据运营需要启用 |

点连接测试，可看到余额和站点名称。密钥沿用本站已有的加密存储，列表和详情不会返回明文密钥。修改连接而未填写新密钥时保留原密钥。

IP 白名单限制的是**本站后端向上游发起余额采购的出口 IP**。在对方的「对接白名单」中登记部署服务器的公网出口 IP；如果服务器通过代理、NAT 或多个节点出网，应登记实际出口。截图里的网页登录 IP 不能据此直接当作服务器出口 IP。上游截图说明，开启资金操作二次验证的账户必须登记白名单才能通过接口扣款。

本站商品浏览器不直接请求采购接口，商户密钥也不发给购买者。

## 导入和销售

1. 在商品映射管理中选 ELLAIXSHOP 连接，读取商品、分类、商户价和库存。
2. 选择要销售的商品导入，可以自动创建分类。商品先作为未上架商品导入。
3. 核对商品描述、兑换方式、售价和购买身份。现有导入默认要求会员购买；如果允许游客购买，在商品管理中调整购买身份。
4. 给 ELLAIXSHOP 商户账户准备足够的预充值余额，再验证白名单和一笔真实采购。
5. 验收成功后上架选中的商品。

本次支持自动发卡、单规格、无额外填写字段的商品。上游以后新增多规格、手动交付或需要买家提供账号/session 的商品时，会保持不可售状态，避免使用错误规格或漏传信息。

下单前还会重新查询实际商户报价与库存。报价高于客户订单保存的成本上限、库存不足、超出上游购买数量限制，或者余额不足时，不会发送扣款采购请求。同步新价格不会改变已经付款订单的历史成本上限；这类历史订单需要单独处理。

## 自动交易流程

1. 客户在本站创建订单，使用本站收款方式付款。目前已实现的自助收款包括 USDT BEP-20，见 [支付说明](usdt-bep20-payments.md)。
2. 本站后端确认订单已付款，采购 worker 读取对应商品/SKU 映射。
3. 数据库原子登记采购提交状态，阻止多个 worker 或重复队列任务重复采购。
4. 后端校验报价、库存和商户余额，调用上游余额支付接口。
5. 保存上游订单号、实际采购金额和卡密。上游订单号按字符串保存，保留可能出现的前导零。
6. 上游立即返回卡密时直接交付；尚未返回时按原上游订单号轮询。客户在本站订单详情查看卡密。

需要启动 Redis 和 worker，运行 `cmd/server -mode all`，或同时运行 API 与 worker。仅启动 API 不能完成付款后的自动采购。对接接口无需填写回调地址，卡密通过采购响应或订单查询获得。

## 异常与人工核对

- 余额不足、库存不足或付款订单成本上限不够时，采购单标记为拒绝，保留已付款订单并提示管理员处理；不会把没有发货的订单标记为交付完成。
- 扣款请求发出后发生超时、非 JSON 响应、返回缺少订单号，或无法确认的业务异常时，采购单进入 `manual_review`。对方官方代码在扣款事务完成后还会读取库存，因此业务错误也不能一律当作未扣款。
- 上游的 `request_no` 重复检查只返回错误，没有提供按这个请求标识找回原订单的接口。此次实现不会自动重发结果不明的采购，避免重复扣款。
- 进程在提交和保存响应之间中断时，定期巡检将超时的 `submitting` 采购单改为待核对；重启后也不会再次采购。
- `manual_review` 不提供直接重试，应先在上游「我的订单」核对原交易和卡密，再由运营处理本地订单。已取得卡密而本地交付写入暂时失败时，可从已保存的原响应或原订单查询恢复，不会重新买一份。
- 上游 Shared API 没有余额采购撤销/退款接口，因此 Acg-Faka 采购单不显示直接取消按钮；本地退款需结合上游实际交易单独处理。

## 可执行配置工具

`scripts/connect-ellaixshop.ps1` 使用本站后台 API 创建或复用该商户连接，测试连接，并可按指定商品 ID 导入未上架商品。它不采购、不自动上架，也不修改已有连接的加价配置。

先在当前进程设置 `ZXA_ADMIN_TOKEN`（本站后台登录 token）和 `ELLAIXSHOP_MERCHANT_SECRET`（上游商户密钥），然后执行：

```powershell
./scripts/connect-ellaixshop.ps1 -AdminBaseUrl 'https://你的商城后端域名' -MarkupPercent 20

# 可选：先导入 Go 和 Plus 两个未上架商品；20% 仅为示例加价。
./scripts/connect-ellaixshop.ps1 -AdminBaseUrl 'https://你的商城后端域名' `
  -MarkupPercent 20 -ImportDrafts -UpstreamProductIds 4,5
```

已有连接的密钥或加价需要更改时，在后台编辑该连接。配置工具会复用已有连接；重复导入由后台返回「映射已存在」等具体结果。

`cmd/upstreamcheck` 只读取连接和商品，可从服务端再次核对余额及商户价格。设置 `UPSTREAM_BASE_URL`、`UPSTREAM_API_KEY`、`UPSTREAM_API_SECRET` 后执行：

```powershell
go run ./cmd/upstreamcheck
```

输出包含余额、商品 ID、进货价和库存，不包含商户密钥。配置工具和只读探测工具都不将密钥写入源码或配置模板。
