# 关于页面

主站 `/about` 按已确认的第二版预览展示品牌介绍、四项服务指引、ChatGPT 充值续费说明、代理合作、客服微信与相关条款入口。经典与 Vault 模板共用 `frontend/user/src/components/StoreAbout.vue`。

## 内容与维护

- 默认中文内容在 `frontend/user/src/content/about.ts`。与商品中文说明一样，该业务文案作为中文内容展示；原有多语言站点设置仍按当前语言及既有回退顺序读取。
- 后台「系统设置 → 站点设置 → 关于页面」已填写的主标题、副标题、介绍、服务标题/项目、联系标题/文案优先于默认值。自定义服务项目可用第一行写标题、后续行写正文；仅一行时直接展示正文。新增充值说明和合作段落由上述内容文件维护。
- 客服微信固定为 `Cqz0924ttxk`，复制操作复用已有剪贴板工具并显示成功/失败反馈。保留已配置的 Telegram、WhatsApp 入口。
- 分销子站继续使用原有关于页和自身配置，不注入主站的商品规则或客服微信。
- 购买须知指向 `/blog/purchase-and-agent-guide`，隐私政策指向 `/privacy`，服务条款指向 `/terms`。

## 充值说明边界

普通 ChatGPT 续费到期后办理，不支持提前续费；20x 续费绑卡与 iOS 覆盖充值继续遵循商品例外。iOS 到期后可能处于宽限期，继续经 iOS 续充须联系客服核对并手动处理。

页面补充 Go 与 iOS 一个月质保，以及质保期内提前掉订阅经核实按剩余天数退款。其他商品已有的质保、开通和退款规则继续以商品详情为准，Gemini 保留所购商品的独立约定。未改写任何原有商品说明、价格、库存、发货指引、公告或法律条款。
