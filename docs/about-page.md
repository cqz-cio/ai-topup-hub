# 关于页面

主站 `/about` 按已确认的第二版预览展示品牌介绍、四项服务指引、ChatGPT 充值续费说明、代理合作、客服微信与相关条款入口。经典与 Vault 模板共用 `frontend/user/src/components/StoreAbout.vue`。

## 内容与维护

后台进入 **系统设置 → 站点设置 → 关于我们 (About)**。所有现有文案会自动填入表单，修改后点击右上角「保存更改」，刷新商城即可看到结果，无需重新发布程序。

- 可编辑顶部小标题、主副标题、介绍标题与正文、服务卡片、充值续费条目与补充说明、代理合作、客服提示、复制按钮文字，以及底部入口名称和地址。服务、充值与入口列表支持添加和删除，每组最多 12 条。
- 顶部语言按钮分别编辑简体、繁体和英文；未填写的语言沿用其他已填写语言。想完全移除某段文字，须清空该字段所有已填写的语言。删除列表条目会同时移除其所有语言。
- 客服微信当前为 `Cqz0924ttxk`，关于页、首页与页脚共用此配置，不能填写手机号。Telegram、WhatsApp 的地址继续在「基础配置 → 联系方式」维护，入口文字可在关于页修改。
- 入口地址接受以单个 `/` 开头的站内路径或完整 `http://`、`https://` 地址。当前仍为购买须知 `/blog/purchase-and-agent-guide`、隐私政策 `/privacy` 和服务条款 `/terms`。
- 内容以纯文本显示，保留换行。页面布局、配色及图标沿用已批准的样式，表单只负责维护内容。

内容独立存储于 `settings.about_page_config`，通过现有设置权限管理。保存只更新该键并清除公开配置缓存，不连带保存注册、订单或其他站点设置。主站公开配置的 `about_page` 提供内容；分销子站继续使用自己的关于页。

首次使用时从 `frontend/shared/aboutPage.ts` 的现有文案及旧 `site_config.about` 覆盖值初始化。保存后显式空值和已删除条目保持为空，不再回填默认内容。旧站点配置保留用于兼容。原有商品说明、公告和法律条款不与关于页面自动同步。

## 充值说明边界

普通 ChatGPT 续费到期后办理，不支持提前续费；20x 续费绑卡与 iOS 覆盖充值继续遵循商品例外。iOS 到期后可能处于宽限期，继续经 iOS 续充须联系客服核对并手动处理。

页面补充 Go 与 iOS 一个月质保，以及质保期内提前掉订阅经核实按剩余天数退款。其他商品已有的质保、开通和退款规则继续以商品详情为准，Gemini 保留所购商品的独立约定。未改写任何原有商品说明、价格、库存、发货指引、公告或法律条款。
