# 商城自动隐藏空分类

首页、商品中心和分类页共用 `frontend/user/src/views/Storefront.vue`。分类入口只保留完整公开商品列表中实际出现的分类，按原分类目录顺序显示；分类接口单独返回的空分类不再显示。

- 页面首次加载、每 60 秒及窗口重新获得焦点/页面恢复可见时，沿用原商品刷新流程重新计算。后台商品重新上架后，分类随下一次成功刷新自动恢复。
- 分类只依据完整商品列表判断，不依据当前搜索结果、售价、可购买状态或库存。仍公开展示的缺货商品保留所属分类；商品列表的后续分页也参与判断。
- 当前选中分类变空时，首页清除分类选择，分类路由替换为 `/products`，保留查询参数和锚点。打开已变空或已删除的分类旧链接，也在成功取得目录后返回全部商品。
- 商品请求失败显示原加载错误，不把失败当作商品下架，不重定向分类链接。分类接口暂时失败时保留上次成功目录；尚未成功获取目录时，不凭缺失的目录误判旧链接。
- 不修改后台分类启用状态或业务数据库，分类记录、商品上架规则、支付、自动采购、历史订单和交付继续由原有流程管理。

单元验证入口：`frontend/user/tests/storefront.test.ts`。浏览器验收使用隔离只读模拟服务测试商品移除/恢复、实际一分钟刷新、分页、搜索和请求失败，再检查正式页面。模拟服务禁止写入和支付采购请求。

发布仅替换上海商城静态资源；保留后台、旧散列资源、商品封面与 Nginx 配置。发布前对两地现有版本、配置和正式业务库做一致性备份。回退仅将上海 `current` 切回本次发布记录中的上一版本，不回灌业务库。

2026-10-28 的本地和正式验收证据保存在私有目录 `work/codex-runtime/empty-categories-release-20261028/`。
