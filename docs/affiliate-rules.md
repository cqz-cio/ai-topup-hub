# 推广返利说明

商城 `/me/affiliate` 在推广链接与统计前展示返利比例、100 元商品本金的计算示例、付款后的确认天数。经典与 Vault 模板共用组件，支持简体、繁体和英文。

## 配置与计算

- 数值来自 `GET /api/v1/public/config` 的 `affiliate.commission_rate`、`affiliate.confirm_days`，与后台「推广返利设置」使用同一配置，不在页面写死运营数值。
- 比例按后端佣金逻辑保留两位小数；示例为 `100 × 比例 ÷ 100`，人民币金额保留两位小数。
- 每次进入页面或切回可见页面重新请求公开配置，不复用全局页面配置。现有后端公开配置缓存有效期为 60 秒，后台保存后可能需等待缓存到期再刷新页面。
- 比例为 0 时明确提示暂不产生返利；确认天数为 0 时写「付款后结算」，不承诺同步实时到账。
- 读取失败或字段异常时隐藏数值并显示重试入口，不能回退成 0% 或立即到账；关闭推广返利时显示关闭说明。

## 规则口径

按已开启返利商品的本金计算，不含支付手续费；整单必须按原价成交。个人专属价、会员价、活动价、批发价、优惠券、自购和分销站订单均不参与。钱包付款本身不影响符合条件的原价订单。

佣金先待确认，确认期从付款时间起算，到期结算到钱包。退款相应扣减返利。钱包收益可消费或申请提现；提现仍需人工审核和打款，具体可提现余额、最低金额和渠道以钱包为准。已有佣金保存创建时的比例和确认时间，不会因为此说明组件更新而重算。
