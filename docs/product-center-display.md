# 商品中心与首页目录同步

经典卡片模式的 `/products` 和 `/categories/:slug` 共用 `Storefront.vue` 的目录展示，通过 `catalogOnly` 隐藏首页专有的介绍、查单区和公告弹窗。

- 共用桌面三列、平板两列、窄屏单列布局；商品图按 5:3 完整展示，名称允许换行，展示交付信息、价格、库存和选购/详情入口。
- 分类与首页一致，按公开分类导航顺序分组，保持组内顺序；Codex 点数资格说明与兑换指引继续使用原组件。
- 读取所有公开商品分页后搜索和筛选，避免商品中心原来先分页、再把 Codex 提到前面的结果。商品数量来自当前 API，不固定写成 18。
- 商品中心分类选择保留分类地址，刷新、详情返回及浏览器导航继续解析当前分类。页面有自己的一级标题和 canonical 地址。
- 首页仍显示原介绍、公告和查单区。商品中心的选购入口与首页一样进入商品详情，继续使用原规格选择和下单流程。
- 使用原商品图片、价格和库存接口，不修改商品数据、支付、订单或后端。Vault 和列表模板保持原配置下的独立展示。

本次日常本机验证覆盖 1920×911、390×844、320×740、三个分类、全角多关键词搜索、无结果恢复、分类刷新、详情导航、首页回归、三种语言与暗色模式。138 项商城测试、类型检查和生产构建通过。私有证据位于 `work/codex-runtime/product-center-display/`，视觉对照见根目录 `design-qa.md`。
