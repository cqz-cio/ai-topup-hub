# 结账刷新恢复与商品搜索

“立即购买”在当前浏览器标签页的 `sessionStorage` 中保存商品、规格、数量及商品快照，最多保留 24 小时。刷新时恢复选择，再通过原有商品接口刷新售价、库存和数量限制；刷新核对完成前不能提交。订单创建成功后清除，重新购买会替换原选择，普通购物车仍独立维护。邮箱、订单查询密码及人工表单填写值不写入这份缓存。缓存损坏、过期或存储不可用时安全降级。

首页、商品列表及 Vault 模板共用标题与分类搜索规则：兼容大小写、全角字符、`Chat GPT`、多关键词，以及 Pro 5/20/50 套餐的 `x`、`×`、`倍` 写法。标题中的 `Pro 20` 可被 `20x` 找到；5x 不会匹配 50x。原商品名称与价格不变。

首页数量显示当前分类与搜索的匹配数。列表搜索先读取该分类的全部公开分页，再匹配、去重和分页，展示匹配总数；清空搜索后恢复接口分页总数。加载失败显示重试，避免把失败误报为零结果；过期的搜索响应不能覆盖新查询。

验证使用日常本地 `5173/8080`，覆盖立即购买连续刷新、数量及规格、替换选择、购物车独立、两个模板与桌面/390/320px，以及别名、多词、无结果、分类和快速改词。自动测试包括缓存损坏/过期/不可用、成功清理及跨 API 分页匹配。所有浏览器验收停在提交订单之前，不进行付款或采购测试。

搜索目前在前台处理完整分类候选集，以适配现有小型目录；目录大幅增长时可将同一匹配规则与计数下沉到服务端。部署仅需商城静态资源，保持后台和支付采购后端原版本。
