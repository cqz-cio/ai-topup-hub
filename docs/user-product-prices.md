# 按用户设置商品单价

后台入口：**用户管理 → 用户列表 → 用户详情 → 设置商品单价**，或用户详情的 **商品单价** 标签。

直接在“此用户单价（CNY）”填写金额，例如 `39.90`，点击 **保存单价**。页面列出全部在售商品，可搜索名称、编号和标识。手机端逐项显示商品、公开单价与输入框。

- 填写的金额只对当前用户生效，登录后的商品列表、商品详情、快速购买、购物车和订单预览使用相同单价。
- 留空或清空后保存，恢复现有的等级、活动与数量定价规则。
- 多规格商品可设置商品通用单价和规格单价；规格单价优先，规格留空时沿用商品单价。
- 专属价不叠加等级、活动和数量折扣；用户自行使用的有效优惠券仍按原规则处理。
- 金额须大于零，最多两位小数。金额按填写值执行，也允许高于公开售价。
- 修改后新订单使用新价格；已生成订单保留已有金额和价格快照。
- 用户所属等级、其他用户的价格、全站公开售价以及供货采购成本分别维护。

会员等级仍可用于批量定价和升级。仅给某个人设置商品价格时，无需先创建会员等级或计算折扣率。

## 接口与数据

管理员鉴权接口 `GET /api/v1/admin/users/:id/prices` 读取用户定价，`PUT` 原子保存完整价格表。请求金额为两位小数字符串，空 `prices` 列表清空专属价。内置 `operations` 和 `support` 角色拥有读写权限，其余角色不自动新增权限。

新表 `user_product_prices` 使用 `(user_id, product_id, sku_id)` 唯一键；`sku_id=0` 表示商品通用价格。保存时校验用户、商品、规格归属、重复项、金额及精度，失败时保留原价格。SKU 价格与商品回退在同一次查询中解析。下单读取失败会返回错误，不按公开售价继续收费。

公开目录仅对鉴权用户返回对应专属价，使用 `private, no-store` 和 `Vary: Authorization`，不接收查询参数指定的用户。公开 `price_amount` 是该用户的单价，`user_price_amount` 标记专属价，`retail_price_amount` 保留公开单价供购物车账户切换时使用。用户 API 目录同步采用同一专属价格解析。

验证使用临时内存数据库与本机日常 `8080/5173/5174` 入口的零消费测试账号，仅预览订单，不提交订单、付款或有效采购。
