# 首页弹窗公告

在[后台](https://124.220.2.69:18888/login)进入 **系统设置 → 站点设置 → 首页公告**。

1. 填写公告标题和内容。编辑器支持文字格式、图片及链接；只填写简体中文时，其他语言使用中文内容。
2. 打开“启用公告”，点击页面上方“保存”。需要定时展示时填写起止时间；留空表示不限制。
3. 用新浏览器会话访问[商城首页](https://www.qzweb.cloud/)检查。关闭过的同一公告在当前会话内不会再次弹出。

访客可选择“今日不再提示”或“不再提示”。标题或内容改变后，旧的关闭记录失效，新的公告会再次提醒。关闭开关、排期尚未开始、排期已结束或内容为空时不显示。

首页弹窗内容与“公告列表”分别维护。发布弹窗不需要创建公告文章。

2026-10-12 已接入正式首页。当前未预填正式内容，管理员填写并开启后生效。该能力使用既有后台配置与弹窗组件。
