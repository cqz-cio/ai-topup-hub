# 注册邮箱验证码发送提醒

注册页在发送验证码接口成功返回后显示“验证码已发送”弹窗，提醒用户查收邮箱；长时间未收到时，可检查垃圾邮件或广告邮件文件夹。首次发送与重新发送均显示提醒；发送中或发送失败时不显示成功弹窗。

弹窗沿用已批准预览的白色圆角卡片、邮件图标、垃圾邮件提示和绿色“我知道了”按钮。点击按钮、关闭图标、遮罩或按 Escape 可关闭；关闭后聚焦到邮箱验证码输入框。键盘焦点限制在弹窗内。保留 60 秒重发倒计时、图形验证码刷新及已填写的邮箱和密码。

经典与 Vault 注册模板共用组件和发送状态，支持简体中文、繁体中文及英文。无需修改邮箱服务、后端验证码规则或站点设置。

浏览器验收通过拦截发送接口模拟成功和失败响应，不实际发送邮件，不创建账号或执行付款采购。记录与截图保存在忽略目录 `work/codex-runtime/email-code-popup-20261013/`。
