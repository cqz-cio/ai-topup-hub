# 付款页返回商品

订单创建成功后，浏览器返回不再停留在已经清空的确认订单页。

- 只购买一种商品（包括同一商品的不同规格）时，返回该商品详情。
- 一次购买多种商品时，返回商品列表。
- 商品详情的立即购买、列表中的快速购买、购物车结算共用该规则，游客与登录用户一致。
- 刷新付款页后仍可返回；浏览器前进恢复原付款页，不重新创建订单。
- 下单失败不修改返回记录，保留本次商品及结算表单；回到详情后可以再次购买。

立即购买优先用付款页替换已经完成的结算历史记录。其他入口在该条结算历史中保存商品返回路径，恢复此记录时由路由守卫跳到商品页；新结算不会被旧记录拦截。付款页原有的「返回订单」链接及订单查询入口保持原意。

实现位于 `frontend/user/src/utils/checkoutNavigation.ts`，经典和 Vault 模板共用。此次仅调整导航，不修改商品售价、订单计价、支付接口、采购或业务数据。
