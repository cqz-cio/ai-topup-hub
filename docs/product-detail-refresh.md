# 商品详情静默刷新

2026-10-21 本地修复，尚未推送或发布。日常预览：`http://127.0.0.1:5173/products/qzweb-76`。

商品详情原来每次更新价格和库存都会设置 `loading=true`，经典和 Vault 模板因此卸载商品区域并显示浅色骨架。每 60 秒及窗口重新获得焦点时均会触发。

`useProductDetail` 现在只在没有当前商品时显示首次加载状态；已有商品静默替换数据，保留图片、规格及数量，库存限制仍实时生效。自动刷新进行中时合并其他自动触发，避免重复请求。首次内容渲染完成后才初始化移动购买条观察器，后台刷新不重复初始化。

网络或服务临时失败时保留已有内容，显示请求失败提示并暂时禁止购买；下一次成功刷新恢复。接口明确返回 401/403/404/410 时清空旧商品。API 客户端在原有错误对象上保留状态码，以区分暂时失败和明确不可用。切换商品、账号和卸载页面仍按原请求序号、账号与路由校验拒绝迟到响应。
