# 分类内价格排序

2026-10-22：已在日常本地实现并验证，尚未推送或发布正式站。

首页、商品中心 `/products` 和分类页 `/categories/:slug` 共用的 `Storefront.vue` 为每个非空分类显示分类标题、商品数量及价格排序选择器。默认从低到高，客户可以分别切换为从高到低；全部商品仍按原分类导航顺序分组，各分类互不影响。

排序使用 `storefrontPrice`，与卡片展示的实际价格一致，包含有效会员/专属价和促销价。按数字比较，0 元有效；无有效价格的商品放末尾，同价商品保持接口原有顺序，不修改接口数组。全部公开分页加载后再筛选、排序，不局限于第一页。

当前页面内切换分类、搜索和自动价格/库存刷新均保留各分类的选择；完整刷新或重新进入页面恢复默认升序。没有把排序写入商品数据或长期浏览器偏好。

Codex 点数与同分类其他商品统一参与价格排序。`CodexCreditsSection` 新增 `products` 插槽供共用目录渲染排序结果，保留点数资格说明、兑换和客服提示；未传插槽的其他模板继续使用原来的点数渲染。此次范围为当前经典卡片商城，独立 Vault/列表模板未改。
